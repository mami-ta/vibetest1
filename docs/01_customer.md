**Claude が埋めた項目には 🔮 が付きます。**

### 3行の評価

2行目「何に困っているか」はすでにかなり具体的ですが、**合計でどれくらいの時間がかかっているか**が数字になっていません。ここに数字が入ると、画面に出すべき項目（何件・何分で終わるか）がもっとはっきりします。今回はこちらで仮の数字を置いて進めます（🔮 が付きます）。

### 今回の題材の絞り込み

入試情報サイトの自動収集（メディア化）や、家族間のリアルタイム共有・ログインは今回は作りません。**麻美さんが自分で確認した情報を、自分で入力して一覧にする「1人用の管理ツール」**に絞ります。理由: 今回のテンプレートは「1種類のデータを登録して・探して・状態を変える」1画面ツールまでが範囲で、複数人ログインや外部サイトの自動取得は第2〜3回で扱うためです。

### 解く課題

- **今その人はどうやっているか**: 紙に書き出して一覧にしている（本人の言葉のまま）
- **かかっている時間 / 費用**:
  🔮 1校・1試験区分の入試要項を確認するのに約30分、月に3〜5校分をチェックするので月2〜3時間。家族で共有できる形に紙で清書し直す時間が月1時間ほど、合計で**月3〜4時間程度**かかっていると思われる。外注（受験コンサルや家庭教師に整理してもらう）だと1回5,000〜1万円程度。
  → 確かめ方:「今の一覧表を作るのに、月にだいたい何時間くらいかけていますか？」
- **なぜ今まで誰も解決していないのか**:
  - [x] データが散っている　[ ] 市場が小さい　[ ] 量が多すぎる
  - [ ] 判断が非定型　[ ] n=1すぎる
  🔮 各校が試験区分ごとに別々のタイミング・別々のページで要項を公開するため、情報がそもそも1か所に集まっていない。かつ志望校の組み合わせは各家庭ごとに違う（n=1に近い）ため、汎用データベースを作っても使い回しにくい。
  → 確かめ方:「今使っている受験情報アプリやサイトはありますか？なぜ使うのをやめた／使わなかったのですか？」
- **このサイトで最初に成立させたいこと（1つだけ）**: 志望校・試験区分を選ぶと、出願日・試験日・合格発表日・入学手続き期限が一覧で見られること（本人の言葉から）

### 出口の3点

**① 誰が払うか**
🔮 使う人と払う人はどちらも麻美さん本人（保護者）だと思われる。受験関連（模試代・塾代・受験情報誌・スタディサプリ等）にお金を払う商習慣は家庭に根付いており、抵抗は少ないと考えられる。
→ 確かめ方:「こういうツールが月500円くらいだったら使ってみたいと思いますか？」

**② どう届くか（下の経路）**
🔮 検索広告よりも、塾の保護者会・PTA・ママ友ネットワーク・受験情報系のSNSコミュニティといった**「下」の経路（紹介・口コミ）**で広がるはずだと思われる。教育分野は個人の実体験の共有が信頼されやすいため。
→ 確かめ方:「もしこれが便利だったら、誰に一番に教えたいと思いますか？」

**③ 受け取れるか**
- 確認したか: いいえ
- 確認した内容: 🔮 学習・スケジュール管理ツールは、投資/金融・医療/健康・法律相談などの要確認業種には該当しないと考えられる。ただし学校サイトの入試要項の内容をそのまま転記・引用する場合は著作権・利用規約の範囲を確認したほうが安全。
  → 確かめ方: 利用しようとしている学校の募集要項ページの利用規約・著作権表記を確認する

### 競合

- **既存の競合**: 河合塾・駿台などの入試情報サイト、Classi、みんなの大学情報、汎用カレンダーアプリ（Googleカレンダー等）
- **DIY競合**: 麻美さん自身がExcel/Googleスプレッドシートを自作する、またはChatGPTに管理表のひな形を作らせる
- **選ばれる理由**:
  🔮 「時間」＝ 毎回複数校のサイトを巡回して情報を探す時間を、志望校・試験区分を選ぶだけの操作に減らせる。「埋め込み」＝ 今すでにある「紙の一覧表を見る」という家庭内の日常フローに、そのまま置き換わって入り込める。
  → 確かめ方:「今の紙の一覧表は、1日にどれくらいの頻度で見返しますか？」
